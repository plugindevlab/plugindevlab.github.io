The workflow map on the workflow page draws the same order.

Ports carry the chain. A connection is allowed when the two ports are the same type, when the input still has room, and when it does not loop back.

How to use it

Pick a component from the list on the left to put it on the board. Click an output port to pick up what it makes, then click an input port to drop it there — or drag from one to the other. Click a wire to remove it, drag a component by its name to move it, and click the name to read what the component does.

Click an input port while holding nothing and the board tells you what that port takes and which components make it. That is the same sentence you get when a connection is refused, so a refusal is never a dead end.

What it checks

  • The two ports must be the same type. Types are the short port nicknames you see on the canvas, which is how the plugin keeps wires alive when a component is renamed.
  • An item input holds one wire; a list input holds several. An output splits to as many inputs as you like.
  • Nothing may loop back into itself.

Those are the only three. Anything the plugin allows, the board allows — including shortcuts that skip a stage. A component counts as connected only when an unbroken chain reaches it from a component that needs no input; anything else is floating, and the counter says so.

What it is not

There is no button that finishes the graph for you, no score and no timer. Nothing is saved: reload the page and the board is empty again.
