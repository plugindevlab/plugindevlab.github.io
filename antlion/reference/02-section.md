## Section

`Antlion ▸ Bowl ▸ Section 2` · ID `SECTION-002` · 9 inputs · 5 outputs

> Turns the tread lines you draw into a tier section — rows, nosing and eye points, and the closed profile the stand is swept from. Draw one line per step; the component sorts them and works out the tiers.

**Inputs**

   - The field, straight from Field. Supplies the focal point

   - Aim the sightlines somewhere else. Wired here it wins over Field Info

4. `Eye Horizontal Offset`  ·  nick `Eye H` — `Number` `item` · default `150 mm / 6 in`
   - How far back from the nosing a seated spectator's eye sits (default 150 mm)

5. `Eye Vertical Offset`  ·  nick `Eye V` — `Number` `item` · default `1200 mm / 48 in`
   - Eye height above the tread, seated spectator (default 1200 mm)

6. `First Tread Height`  ·  nick `First H` — `Number` `item` · optional
   - Height of the first step above field level. Unwired = take it from the drawn lines

7. `Slab Thickness`  ·  nick `Slab T` — `Number` `item` · default `200 mm / 8 in`

8. `Panel Values`  ·  nick `Panel` — `Object` `item` · optional

**Outputs**

   - The closed profile per tier - what Stand sweeps into a solid

## Auto Section

`Antlion ▸ Bowl ▸ Section 2` · ID `SECTION-001` · 19 inputs · 7 outputs

> Works out the risers for you. Give it the tread depths and the minimum C-value you want to hold, and it raises each step by the smallest Riser Step increment that still clears that C-value - the shallowest bowl that meets the target. The front row starts on the start line, so wire the same field, focal point and start line that Section takes. Bake tread_lines if you want to fine-tune the steps by hand in Section afterwards.

**Inputs**

0. `Field Info`  ·  nick `Field` — `Object` `item` · optional

   - Aim the sightlines somewhere else. Wired here it wins over Field Info

2. `Base Line`  ·  nick `Base` — `Curve` `item` · optional
   - The faceted line the stand is built on. Its outward normal sets which way it faces

3. `Rows Per Tier`  ·  nick `Rows` — `Integer` `list` · optional
   - How many steps each tier has, front row included - one per tier. Two is the minimum (no default - you set this)

4. `Front Treads`  ·  nick `Front T` — `Number` `list` · optional
   - Depth of the front step - one per tier. This is usually the deep one (no default - you set this)

5. `Other Treads`  ·  nick `Other T` — `Number` `list` · optional
   - Depth of every step above the front one - one per tier (no default - you set this)

6. `Tier Step Back`  ·  nick `Step Back` — `Number` `list` · optional
   - How far the tier behind starts back from the last nosing below - one per gap between tiers. Negative reaches out over it (no default - you set this)

7. `Tier Step Up`  ·  nick `Step Up` — `Number` `list` · optional
   - How high the tier behind starts above the last nosing below - one per gap between tiers (no default - you set this)

8. `Minimum C-Values`  ·  nick `Min C` — `Number` `list` · optional
   - The C-value every row must hold - one per tier, or one for all (default 100 mm)

9. `Minimum Riser`  ·  nick `Min Rise` — `Number` `item` · default `150 mm / 6 in`

10. `Maximum Riser`  ·  nick `Max Rise` — `Number` `item` · default `550 mm / 22 in`
   - Tallest riser to build. Rows needing more get capped and warned. 0 = no cap (default 550 mm)

11. `Eye Horizontal Offset`  ·  nick `Eye H` — `Number` `item` · default `150 mm / 6 in`
   - How far back from the nosing a seated spectator's eye sits (default 150 mm)

12. `Eye Vertical Offset`  ·  nick `Eye V` — `Number` `item` · default `1200 mm / 48 in`
   - Eye height above the tread, seated spectator (default 1200 mm)

13. `First Tread Height`  ·  nick `First H` — `Number` `item` · optional
   - Height of the first step above field level. Unwired = sit it on the start line

14. `Start Distance`  ·  nick `Start D` — `Number` `item` · optional
   - How far the first step sits in front of the focal point. Used only when Base Line is unwired

15. `Slab Thickness`  ·  nick `Slab T` — `Number` `item` · default `200 mm / 8 in`
   - Thickness of the stand slab. Set it once here - everything downstream reads it (default 200 mm)

16. `Riser Step`  ·  nick `Rise Stp` — `Number` `item` · default `10 mm / 0.5 in`
   - Risers round up to a whole multiple of this, so they set out on site (default 10 mm)

17. `Flip X` — `Boolean` `item` · default `false`
   - Flip the section drawing left-right. It runs along the field long axis, +X side by default - true draws it the other way (default false)

18. `Panel Values`  ·  nick `Panel` — `Object` `item` · optional
   - Every value from Input Panel, as one bundle. Anything you wire in yourself wins over it

**Outputs**
