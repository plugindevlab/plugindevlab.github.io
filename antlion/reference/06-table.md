## Excel Workbook

`Antlion ▸ Table` · ID `IO-007` · 6 inputs · 3 outputs

> Creates an .xlsx workbook you can fill in with Excel, with the input pages already laid out, and hands the reference to Table In and Table Out. Give the project folder, optionally a file name (the folder name is used when empty), and press Run - an existing file connects, a missing file is made there. No internet or sign-in is needed, so this is the path that works on closed networks. The reference is saved with the Grasshopper file; because it is a file path, moving the workbook or the .gh means picking the file again. The 10-series pages are yours and are written only at creation; the 80-series pages belong to the plugin.

0. `Field Info`  ·  nick `Field` — `Object` `item` · optional
   - Optional. Seeds the focal-to-start-line reference the preview columns need

1. `Focal Point`  ·  nick `Focal` — `Point` `item` · optional
   - Optional. Overrides the field's focal point, same as Section

2. `Base Line`  ·  nick `Base` — `Curve` `item` · optional
   - The faceted line the stand is built on. Its outward normal sets which way it faces

3. `Run` — `Boolean` `item` · default `false`
   - Wire a Boolean Button. Nothing touches the disk on an ordinary solve

4. `Folder Path`  ·  nick `Folder` — `Text` `item`
   - Folder the workbook lives in (e.g. C:\\project). It must exist - it is not created for you. The file name comes from File Name, or from the folder name when File Name is empty

5. `File Name`  ·  nick `Name` — `Text` `item`
   - Optional workbook name (e.g. stadium). Empty uses the folder name. The .xlsx is added for you. If that file exists Run connects to it; if not, Run makes it there

**Outputs**

0. `Book` — `Object` `item`
   - The workbook reference. Wire it into Table In and Table Out

1. `Path` — `Text` `item`

## Table In

`Antlion ▸ Table` · ID `IO-005` · 2 inputs · 8 outputs

> Reads the workbook's input pages and gives you the values to build from. Wire the workbook reference and press run. Values are looked up by column and key name, so inserting rows or reordering columns in the spreadsheet is safe. What was read is stored with the Grasshopper file, so the canvas keeps working without pressing run again.

**Inputs**

0. `Book` — `Object` `item`
   - Wire from Google Workbook or Excel Workbook

1. `Run` — `Boolean` `item` · default `false`
   - Wire a Boolean Button. Nothing goes over the network on an ordinary solve

**Outputs**

0. `Table Data`  ·  nick `Table` — `Number` `tree`
   - One branch per step: row index, tread depth, riser height. Blank rows are left out

1. `Eye Horizontal Offset`  ·  nick `Eye H` — `Number` `item`
   - How far back from the nosing the eye sits

2. `Eye Vertical Offset`  ·  nick `Eye V` — `Number` `item`
   - Eye height above the tread

3. `Slab Thickness`  ·  nick `Slab T` — `Number` `item`
   - Thickness of the stand slab

4. `Minimum C-Value`  ·  nick `Min C` — `Number` `item`
   - Smallest acceptable C-value

5. `C-Value Mode`  ·  nick `C Val` — `Text` `item`
   - STANDARD or VARIABLE_CORNER

6. `Book` — `Object` `item`
   - The whole workbook as read. For diagnostics and for columns without a port

7. `Debug` — `Text` `item`
   - One-line diagnostic. Copy this text when reporting a problem

## Table Out

`Antlion ▸ Table` · ID `IO-006` · 3 inputs · 3 outputs

> Writes analysis results into the workbook's result pages. Wire the workbook reference and the result objects - section, analysis, seat map or C-value map - and press run. Each result type knows which page it belongs on. The plugin owns those pages and rewrites them every run; copy rows into the input pages if you want to keep and edit them.

**Inputs**

0. `Book` — `Object` `item`
   - Wire from Google Workbook or Excel Workbook

1. `Results` — `Object` `list` · optional
   - Result objects to write, in any combination. Anything with no table form is skipped

2. `Run` — `Boolean` `item` · default `false`
   - Wire a Boolean Button. Nothing goes over the network on an ordinary solve

**Outputs**

0. `Success` — `Boolean` `item`
   - True when the last write finished, or was skipped because nothing changed

1. `Written` — `Text` `list`
   - What landed where - one line per page

2. `Debug` — `Text` `item`
   - One-line diagnostic. Copy this text when reporting a problem
