   - Wire a Button to move the perspective viewport to this seat. One press, one jump

8. `Live` — `Boolean` `item` · default `false`
   - On = the viewport follows every change, so you can look around by sliding (default false)

9. `Address` — `Text` `item` · optional
   - A seat address like A0 05 S 25. Wired, it wins over Tier, Zone and Seat Number

10. `Panel Values`  ·  nick `Panel` — `Object` `item` · optional
   - Every value from Input Panel, as one bundle. Anything you wire in yourself wins over it

**Outputs**

   - Where the camera stands - the same point the C-value map measures from

1. `Focal Point`  ·  nick `Focal` — `Point` `item`
   - What the seat is graded against, before Yaw and Pitch

2. `Sight Line`  ·  nick `Sight` — `Line` `item`
   - The eye-to-target line actually applied to the viewport

## View Limit

`Antlion ▸ Bowl Analysis` · ID `VIEWLIMIT-001` · 7 inputs · 7 outputs

> Draws the optimum and maximum viewing distance circles for a sport and counts how many seats fall outside. Reference only — it never removes a seat; wire limit_curves into Cut if you want it enforced.

**Inputs**

0. `Field Info`  ·  nick `Field` — `Object` `item`
   - The field, straight from Field. Sets the sport and what distances are measured from

1. `Seat Result`  ·  nick `SRD` — `Object` `item` · optional
   - The seat layout from Seat or Cut. Wire it to get the seat counts

2. `Sport Mode`  ·  nick `▾ Sports` — `Text` `list` · optional · dropdown
   - Which sports to draw limits for - one per sport. Empty = the field's own sport

3. `Optimum Overrides`  ·  nick `Opt Ovr` — `Number` `list` · optional
   - Set the OPTIMUM viewing radius yourself - one per sport, matching Sport Mode. Empty = the built-in sourced value

4. `Maximum Overrides`  ·  nick `Max Ovr` — `Number` `list` · optional
   - Set the MAXIMUM viewing radius yourself - one per sport, matching Sport Mode. Empty = the built-in sourced value

5. `Show Reference`  ·  nick `Show Ref` — `Boolean` `item` · default `false`
   - For sports with no published limit, borrow the soccer figures (default false)

6. `Panel Values`  ·  nick `Panel` — `Object` `item` · optional
   - Every value from Input Panel, as one bundle. Anything you wire in yourself wins over it

**Outputs**

0. `Limit Curves`  ·  nick `Limits` — `Curve` `list`
   - Reference envelopes: optimum, maximum, quality circle. Advisory - nothing is cut

1. `Limit Labels`  ·  nick `Lim Lbl` — `Text` `list`
   - Sport, kind, radius, datum, source and whether the value is sourced or user-set

2. `Seats Inside`  ·  nick `Inside` — `Integer` `item`
   - Seats inside the maximum limit (-1 = no seat layout wired)

3. `Seats Outside`  ·  nick `Outside` — `Integer` `item`
   - Seats outside the maximum limit (-1 = no seat layout wired)

4. `Seats Beyond Points`  ·  nick `Beyond` — `Point` `list`
   - Positions of the seats outside the maximum limit - where, not just how many

5. `Report` — `Text` `list`
   - Sport, limit radii, seats inside versus outside

6. `Debug` — `Text` `item`
   - One-line diagnostic. Copy this text when reporting a problem
