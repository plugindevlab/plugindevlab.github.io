# Antlion Tutorials

Longer, task-shaped guides. Where the [component reference](../reference/index.md) tells you what a
port does, these pages tell you how a job gets done — and state the rules that are not
visible on screen.

- [**Custom Axis** — placing sections on curves you draw](custom-axis.md)
  Bring axis lines in from a CAD drawing, or put sections exactly where you want them.
  Covers axis numbering, tangent extension, and the gap warnings that tell you a curve
  was not the one you meant.

More guides land here as the plugin grows. If you are stuck on something that is not
covered, the reference pages are generated from the plugin itself and always match the
version you are running.
